# Architecture review — 2026-09-28

Commit: 851ef8e. First run: model created from scratch (no prior model existed).

## What the model captures

RS Planner is a single internal Next.js/Supabase tool with no plugin/tenant
verticals, so the model has core capabilities only, no `domain` elements:

- `identity` — auth pages, session middleware (`src/proxy.ts`), Supabase clients, `profiles`
- `shell` — app shell, theming, shared UI kit, shared types/utils
- `team` — roster, availability, `team_members`, `time_off`
- `projects` — client projects
- `timeline` — scheduling/allocations, the highest-churn business capability
- `competencies` — skills/technology catalog and project experience
- `publicApi` — the API-key-guarded public HTTP surface (`src/app/api/**`), also owning the thin `mcp/competency` MCP-server client that wraps it

Two `app` deployables: `site` (the Next.js app) and `competencyMcp` (the
standalone MCP server in `mcp/competency`), plus two actors (`teamMember`,
`llmAgent`) and one `store` (`db`, Supabase Postgres).

## Key decisions

| Decision | Source | Reason |
|---|---|---|
| No `domain` elements | Auto | The app has no plugin/tenant-swappable verticals — every capability inventoried (people, projects, timeline, competencies, identity, the public API) is something every part of the app needs, not something a customer would swap out. |
| `mcp/competency/**` owned by `publicApi`, not a separate capability | Auto | It is a stateless HTTP client with no business logic of its own (`mcp/competency/src/index.ts`); it exists only to expose `publicApi`'s interface to LLM agents. |
| `src/lib/types.ts` and `src/lib/utils.ts` owned by `shell` | Auto | Both are imported by every other capability with no single functional owner; `metrics.mjs` flagged `src/lib/types.ts` as unowned on the first pass — folded into `shell` and re-validated. |
| No coverage tool installed to fill `coverage: null` | Auto | `context/foundation/tech-stack.md` records no test runner beyond `vitest run`; installing a coverage tool is out of scope for this skill (AR-001 records the gap instead). |
