## Notes

Dodać możliwość oznaczenia, że dany user jest niedostępny przez część dnia
(np. 3h, okno 13:00–16:00) zamiast tylko całego dnia. Model: konkretne okno
zegarowe (start_time / end_time). Założenie: blok godzinowy dotyczy jednego dnia.
Całodniowa nieobecność (urlop/L4) działa jak dotychczas — bez zmian.
