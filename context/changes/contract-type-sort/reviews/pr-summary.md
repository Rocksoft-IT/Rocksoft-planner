**What this delivers:** Team members can now have a contract type — UoP, B2B, or
Freelance — recorded on their profile, so you can track how each person is engaged.
Leaving it unset is fine; nothing else about creating or editing a team member changes.

**Please check on the preview:**
- Open a team member's profile, set a contract type (e.g. "B2B"), save, and reopen it
  to confirm it's still shown
- Clear a contract type you had set, save, and confirm it now shows as unset
- Confirm you can still add or edit a team member without picking a contract type

type can be saved. Once that's done, this is ready to check on the preview. Sorting
